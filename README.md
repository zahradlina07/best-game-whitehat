# Block Dodger

Block Dodger is an original arcade game for desktop browsers. Dodge falling danger blocks, catch gold coins, survive advancing levels, and chase a high score.

## Play

Serve the repository directory and open `game/index.html`, or run:

```sh
node serve.ts --port 8080
```

Move with the left and right arrow keys or A/D. Press P to pause and Space or click to start or restart.
